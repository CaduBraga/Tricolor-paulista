# São Paulo Futebol Clube

Este é um site simples sobre o **São Paulo Futebol Clube** (SPFC), um dos clubes mais tradicionais e vitoriosos do Brasil. O projeto é uma página que traz informações sobre o clube e seu estádio, o Morumbi.

## Estrutura do Projeto

O projeto é composto por um arquivo HTML simples com estilos embutidos em CSS. Ele é dividido em três seções principais:

- **Cabeçalho (Header):** Exibe o nome do clube e o título da página.
- **Conteúdo (Section):** Apresenta informações sobre o clube e o estádio, com links para mais detalhes no Wikipedia.
- **Rodapé (Footer):** Contém os direitos autorais do clube.

## Tecnologias Utilizadas

- **HTML:** Para estruturação do conteúdo da página.
- **CSS:** Para estilização da página.
